# Bronnen (te verifiëren)

| Bron | URL-startpunt | Formaat | Notities |
|---|---|---|---|
| Zorginzicht openbare data | https://www.zorginzicht.nl/openbare-data | downloads per sector | Volumes en uitkomstindicatoren msz; ook basis voor ZorgkaartNederland Zorgvolumekaart |
| Wachttijden | https://www.zorgkaartnederland.nl/wachttijden | HTML | NZa levert elke 2 weken aan; niet gecontroleerd op juistheid. Check of NZa zelf open data publiceert |
| Contract-PDF's ziekenhuizen | bv. https://www.avl.nl/media/tpudg0no/avl_contracten-zorgverzekeraars-2026.pdf | PDF (tabel) | Per ziekenhuis eigen opmaak en peildatum; vaak met omzetplafond-markering |
| Zorgzoekers verzekeraars | per concern | JS-webapp | Headless browser (Playwright); structuur wijzigt soms |
| Consumentenbond contracteringsonderzoek | consumentenbond.nl (nieuws) | afbeelding | 4 meetmomenten per seizoen; geschikt als controle, niet als bron |
| Polissen | https://www.zorgverzekeringskaart.nl | per polis kaart | Beheerd door Zorgverzekeraars Nederland; geen export |
| Reviews | ZorgkaartNederland, Zorgwijzer | HTML | Alleen cijfer + aantal opslaan |
